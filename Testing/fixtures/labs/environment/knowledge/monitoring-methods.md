# Demonstration monitoring protocol

This is a demonstration protocol, not a published scientific finding. For station observations, preserve the original CSV and its exact units and column headers. A bounded sample can establish the schema but cannot establish the quality of every observation. Report missing values and duplicate station-time records. Flag unusual temperatures for review rather than silently discarding them. Compare stations over time using labelled axes and state the anomaly rule and threshold. A station's depth or location may be a confounder; a difference in averages alone is not causal evidence.

For taxonomic names, the optional GBIF connector can provide an external match. Report the returned match type and confidence. A taxonomic match is not evidence of an occurrence at the monitoring site.
